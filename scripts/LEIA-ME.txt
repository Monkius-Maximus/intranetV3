==========================================================
 Intranet SEPLAG — pacote de instalacao OFFLINE
==========================================================

Este pacote contem TUDO que o servidor precisa. O servidor NAO acessa a
internet em nenhum momento.

Conteudo:
  deps/      Node (tarball) + pacotes .deb (PostgreSQL 16, nginx, UFW)
  app/       backend compilado, frontend buildado e SQL do banco
  config/    nginx-intranet.conf e intranet-backend.service
  scripts/   instalador e utilitarios

----------------------------------------------------------
 INSTALACAO (no servidor Ubuntu 24.04, com sudo)
----------------------------------------------------------
  1. Copie este pacote para o servidor (pendrive).
  2. Extraia:        tar xzf intranet-bundle-*.tar.gz
  3. Entre na pasta: cd intranet-bundle-*
  4. Instale:        sudo bash scripts/install-server.sh

  Na PRIMEIRA instalacao sera solicitada a senha do usuario 'admin'.
  Ao final, o instalador mostra a URL de acesso, o hostname e o IP para
  o time de TI cadastrar no DNS (Windows Server).

----------------------------------------------------------
 OPERACAO
----------------------------------------------------------
  Status:        bash scripts/status.sh
  Backup banco:  sudo bash scripts/backup-db.sh
  Atualizar:     sudo bash scripts/update-server.sh   (use um bundle novo)
  Logs:          journalctl -u intranet-backend -f

Reinstalar/atualizar com um bundle novo PRESERVA o banco de dados.
